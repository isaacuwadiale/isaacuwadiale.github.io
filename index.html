Why Glouf

Because looks can be deceiving.

Counterfeit products and fraudulent documents can imitate the appearance of originals. Glouf is being built to connect people to registered information through scannable codes and a clearer verification journey.

Does scanning a QR code alone prove authenticity?

No. The code must be checked against Glouf's registered records, and the result must account for code status and other verification signals. A scan is a verification aid, not an unconditional guarantee.

Can Glouf handle sensitive documents?

Document workflows should use access controls and display only authorised information. Sensitive identity details and full document images should not be exposed publicly by default.
